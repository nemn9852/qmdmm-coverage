114 * A Client maintains the connection to a server (through a @c Socket) and the local
115 * @c Room where the game state is mirrored. It converges to a pure connection: the
116 * controller interface (requests / notifications / replies / speech / operation) lives
117 * on its own @c Agent (see @c Client::agent()), which a UI or an automated player drives.
118 *
119 * The client's objectName is its playerName: the constructor assigns a random objectName,

121 * the playerName. playerName is therefore not configurable by design, and the operation
