12 // The horse style (issue #6 C3, the sibling of the knife style C2). Where the
13 // knife style sharpens a knife and walks up to whatever it wants dead, this one
14 // rides: the horse is bought and sharpened first (Q4: horse damage, then knife
15 // damage, then max HP), and what the horse is for is the pull-kick loop. A kick
16 // costs nothing and needs nothing but a horse and a peer in the same city -- and
17 // it throws that peer back into the Village by itself (see Player::kick()). So
18 // the round goes: drag a peer out of the Village into the city this bot stands
19 // in (LetMove), kick it, and do it again. A peer that has to spend its own
20 // rounds on getting away is a peer that is not spending them on anything else,
21 // and every kick lands without this bot ever paying a city's punish for a slash.
22 //
23 // The Village is where that loop is not available: a kick is forbidden there
24 // (Player::canKick()), and with LetMove turned off the rules do not allow
25 // dragging a peer anywhere at all (LogicConfiguration::enableLetMove()). What is
26 // left then is ordinary play -- Q4's "walk up and slash it". That walk goes
27 // through the Village anyway (every place is adjacent only to the Village), and
28 // the Village is where a slash is free, while a city charges the slasher its own
29 // HP for one; so the Village is where this style is happiest to meet a peer. A
30 // city slash is still taken when it is survivable (see Bot::canSlashSafely())
31 // -- passing it up is not a vow of poverty, it is a preference for the kick,
32 // which is free.
33 //
34 // A round starts every player bare, at full HP and at its own seat (see
35 // Room::prepareForRoundStart()), and it holds as many action times as it takes
36 // for it to be over. So the horse is bought again at the start of every round,
37 // and the loop is played out inside one round.
38 //
39 // Every handler keeps the reply-or-giveUp contract: it always answers with a
40 // legal reply or explicitly gives up, so the bot never stalls a match until the
41 // server times it out.
